# 博识堂 · 托管台账

托管人员记录与每日人数总览，通过 GitHub Pages 发布。

**线上地址**：https://lhliang-lab.github.io/boshitang-tuoguan/

## 文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 托管人数总览页（本地名为「托管人数总览.html」） |
| `data.js` | **每日数据文件——每天只需改这一个** |
| `entry.html` | 托管数据录入页（本地名为「托管数据录入.html」），填表生成 data.js |

## 每日更新人数（三种方式任选）

1. **直接改**：在 GitHub 网页上打开 `data.js` → 点铅笔图标编辑 → 改括号里的数字 → Commit。约 1 分钟后刷新线上页面生效。
2. **用录入页生成**：打开 `entry.html`，填当天人数 → 生成 → 下载 `data.js` → 覆盖本地文件并重新上传（或把内容发给李老师 / AI 代改）。
3. **口头交代**：把当天数字发给李老师或 AI，由其修改 `data.js` 并上传。

## 页面内容

- 托管总人数（按初一 / 初二 / 初三分布）
- 上课人数
- 午托 / 晚托吃饭人数（后厨备餐看板）

> 内部资料，仅含汇总人数，不含学生姓名。
