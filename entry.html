  2. 点「下载 data.js」，用下载的文件覆盖「托管台账」文件夹里的旧 data.js；

直连 GitHub 更新（可选）

填好上面的数字后，点「一键更新」可直接把 data.js 写入 GitHub 仓库，约 1 分钟后线上页面自动生效——不需要下载、也不需要上传文件。每次更新还会自动在「更新记录」里留一条档（总览页可查最近 10 次）。
首次使用需配置一次访问令牌：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 生成新令牌，仓库只选 boshitang-tuoguan，权限给 Contents: Read and write，把生成的令牌（github_pat_ 开头）粘贴到下面保存即可。
令牌只保存在你自己电脑的浏览器里（localStorage），不会发送到 GitHub 以外的任何地方。建议使用仅授权本仓库的细粒度令牌，并每隔几个月更换一次；在公用电脑上用完请点「删除令牌」。
